# My Anime List V20

Static frontend for GitHub Pages.

V20 can use a separate Cloudflare Worker backend for AniList/Jikan proxying and server-side SubDL/Kodik credentials.

After deploying the Worker, open the site -> Settings -> Server project -> paste the Worker URL -> Test.

## V20.3 Player Polish
Custom player controls, timeline/buffer/OP-ED markers, track menus, subtitles UI, PiP/fullscreen/mini-player, auto-next countdown and playback error states.
