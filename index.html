Источники

Публичный клиент не хранит секретные API-ключи. AniLiberty/AnimeVost работают как доступные источники, а Kodik/SubDL подключаются через серверный Cloudflare Worker. Свои разрешённые HLS/MP4 и дорожки можно добавлять через Manifest.

🔒 API-ключи хранятся только на сервере Kodik token и SubDL key больше не вводятся в браузере. Они должны лежать в Cloudflare Worker Secrets.
